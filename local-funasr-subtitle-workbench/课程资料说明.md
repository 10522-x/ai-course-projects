# 本地语音识别字幕项目

来自本机 FunASR 项目的源码副本，含原始英文 README.md、网页和脚本。
需要 Windows、Python 3.12 和联网安装依赖、下载模型。文件不是一键免安装程序。

在解压目录用 PowerShell 依次运行：
1. .\scripts\setup.ps1
2. .\scripts\download_model.ps1
3. .\scripts\start.ps1

然后打开 http://127.0.0.1:8000。端口占用时先检查现有服务。
只打包源码；不含 .venv、models、缓存、jobs、日志、个人视频及已有字幕。
字幕存在识别误差。校正映射是文字替换，不等于训练模型；
说话人分组为匿名标签，不等于识别真实身份。以实际源码和 README 为准。
本次只核对打包完整性，没有在干净电脑重新安装、下载模型或启动验证。

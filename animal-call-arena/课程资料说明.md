# 动物模仿大赛：本机静态学习项目

这是本机 animal-voice-arena 当前文件的静态副本，不是 Google AI Studio 导出的原始版本。
包含 index.html、css、js 和 assets。无需后端；请通过 localhost 的 HTTP
服务或 HTTPS 站点访问，使用录音前允许麦克风。直接双击不保证加载音库。

如有 Python，可在解压目录运行 python -m http.server 8080，
再访问 http://localhost:8080。静态模式会探测 /api/healthz 后回退到本地音库；
该探测返回 404 是预期行为。没有打包数据库、用户成绩或录音。

assets/credits.json 保留每条录音的作者、原始链接和独立许可；
音频文件原样复制，使用与再分发请遵守对应条目的许可。
图标的 Lucide 许可在 LUCIDE-LICENSE.txt。
本次只核对源码、引用和打包完整性，未重新验收录音评分算法。

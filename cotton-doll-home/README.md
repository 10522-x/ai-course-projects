# 瑣儿的小小生活

基于 Three.js + Vite 的全屏互动玩偶屋。没有登录、联网服务或后端依赖。

对应课程：[用 Vibe Coding 做棉花娃娃小家](https://www.bilibili.com/video/BV1wyxL6UEMd)。本目录是从课程项目整理的可运行版本。

## 运行

使用 Node.js 22.12 或更新版本：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://localhost:5173`。同一局域网内的手机可以访问电脑的局域网 IP 和对应端口。

```sh
npm run build
npm run preview
```

构建结果位于 `dist/`，可部署到静态托管服务。

## 小屋

- 点击家具或底部图标直接安排活动，不再出现确认浮层；鼠标悬停显示家具名称或按钮用途。
- 鼠标拖动旋转、滚轮缩放；触屏单指旋转、双指缩放。
- 顶部可以暂停、继续、重置视角和切换自主生活。
- 调色盘选择整体背景色；时间滑杆切换白天、黄昏与夜晚，窗外景色和室内灯光随之变化。两项设置保存在本机，暂停时仍可调整。
- 顶部人像图标进入 `model-studio.html`：三版模型对照、素体/穿衣切换和正侧背观察。
- 三版分别为「新图校准」「圆脸短身」「软团比例」；点击「带回小屋」会在本机保存所选版本与服装状态。
- 暂停会冻结角色、行为时钟和动画，镜头操作不受影响。
- 自主生活先玩积木，之后优先体验尚未做过的活动，再随机轮换。
- 八种活动：烹饪、吃饼干、阅读、小睡、打扫、画画、玩积木、抱靠垫发呆。
- 指令切换会先结束拿取、归还当前道具，再沿避障路径前往新目标。

## 模块

| 文件                      | 职责                                                 |
| ------------------------- | ---------------------------------------------------- |
| `src/scene.js`            | 玩偶屋、灯光、相机、渲染和尺寸适配                   |
| `src/character.js`        | 连续发型、圆润素体、服装配件和身体关节               |
| `src/character-design.js` | 三版比例参数、哑光材质、半眯眼与小包图案             |
| `src/model-studio.js`     | 可旋转的三版对照视图、服装切换与本地选择             |
| `src/materials.js`        | 布料、木纹、拼布、绘本与画纸纹理                     |
| `src/shapes.js`           | 复用几何体与造型工具                                 |
| `src/config.js`           | 家具位置、占地、额外障碍、接近点、动作姿态和中文文案 |
| `src/furniture.js`        | 家具、物件与道具归位记录                             |
| `src/navigation.js`       | PathFinding.js A\* 寻路、障碍扩张和连续路线检查      |
| `src/behavior.js`         | 自主调度、用户指令优先、行走、转身和暂停             |
| `src/activities.js`       | 活动进入、更新、退出与手部道具管理                   |
| `src/interaction.js`      | 家具单击、悬停提示、中文工具栏和氛围设置             |
| `src/batching.js`         | 按材质与家具归属合批静态模型，保留独立可动道具       |

新增家具时，在 `config.js` 声明配置，并在家具工厂添加造型。新增活动在 `activities.js` 添加道具规格、姿势与活动更新；行走、暂停和清理流程无需重写。

## 角色与素材

公开版不包含原始参考照片、照片查看入口或临时部署配置。三版模型由代码生成，运行不需要原照片。

木纹、场景布纹、角色几何、书封、拼布被子、地毯和绘画均由项目本地代码创建，运行时不请求第三方图片。瑣儿采用用户提供的虚构创作设定，不模拟真人面貌。

## 验证

```sh
npm test
npm run test:e2e
npm run test:models
npm run build
npm run test:production
```

浏览器检查需要本机 Google Chrome。端到端与三版对照检查还需要已启动本地开发服务器，可通过 `TEST_URL` 指定测试地址。

生产检查会临时启动 4173 端口的预览服务，确认生产页面可用、阅读活动可进入，且没有暴露调试接口；检查后自动关闭该预览服务。

- 单元测试检查八种活动之间的 64 组路线与实物障碍。
- Playwright 检查所有活动的状态、道具、连续画布像素变化与自然退出。
- 验证家具真实射线点击、指令覆盖、道具归位、暂停后的逐像素冻结、旋转、缩放和重置。
- 验证 1440 × 1000 桌面、390 × 844 和 360 × 640 竖屏，以及 844 × 390 横屏。
- 使用触屏事件验证单指拖动、双指缩放和不误触家具。
- 截图与机器可读报告生成在 `test-results/`，不提交 Git。

仅开发环境的 `?qa=1` 地址暴露确定性测试接口，生产构建不包含该接口。

## 性能

角色使用连续参数曲面，不再生成绒毛实例；静态室内物件按材质合批，纹理复用，小屋像素比上限 1.65，对照视图上限 1.7。仅一盏主光生成阴影；没有后处理泛光、景深或持续昂贵的粒子系统。清理渲染器、几何体、纹理、控件和事件监听，支持 Vite 热更新。
